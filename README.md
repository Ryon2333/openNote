# OpenNote 0.4 开发版

正式需求为 docs/REQUIREMENTS.txt，从附件《OpenNote Android 开发需求与验收规范》v1.0全文提取。进展和真实验证见 PROGRESS.md、TEST_REPORT.md。这不是全功能 Goodnotes/MarginNote 替代品。

首轮切片：离线 PDF SAF 导入，单页按需阅读/双指缩放，原生矢量手写/荧光/整笔擦，页内拖动留白和调整/删除/撤销，SQLite WAL 事务保存，标注栅格化的流式 PDF 导出。源PDF不修改；没有INTERNET权限、账号或遥测。

## Windows 11 / Android Studio

1. 解压到英文路径（例如 D:\Projects\OpenNote），Android Studio → Open → 本文件所在根目录。
2. Gradle JDK选择 JDK 17；不要用 JDK25。Wrapper8.9，AGP8.7.3，Kotlin2.0.21。
3. SDK Manager安装Platform35、Build-Tools35.0.0；IDE创建本机local.properties。交付不含开发机器绝对路径。
4. 首次同步需要下载锁定开发依赖；安装后使用完全离线。
5. OPPO Pad5开启USB调试，连接电脑并确认授权，选择app → Run；或直接安装交付Debug APK。
6. `gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。APK在 app/build/outputs/apk/debug/。
7. 连接设备后 `gradlew.bat :app:connectedDebugAndroidTest`。仪器测试不替代真实触控笔延迟和30分钟体验测试。

## 使用

笔记库 → 试用示例 / 导入 PDF。默认仅触控笔书写，无笔测试可在「画笔」面板开启手指书写。

编辑器顶部「文件 / 工具栏 / 画笔 / 笔盒 / 页内笔记 / 翻页」分别控制模块展开与收起，使用 180–220ms 的淡入和尺寸动画。文件标签可切换、关闭；会话内保留各页的缩放与阅读位置；「＋ 打开文件」返回笔记库选择其他文件，保留已有标签。关闭前原子提交待保存页面与当前标题/页码，失败保留文件并标记未保存。标签和撤销历史属于当前会话，重启后从笔记库重新打开。

点击「钢笔 / 荧光笔」打开选笔面板：圆形色板、笔宽滑块与线条预览；「加入笔盒」保存当前颜色、宽度和类型，点击笔盒预设快速换笔。「整理」可移除预设，最多 12 支，设备上持久保存。基础笔目前为固定宽度，没有压力笔尖曲线。

「插入留白」在页面按住并向下拖，松手插入；轻点插入默认高度。已有留白底部显示蓝色 ↕ 手柄与实时毫米高度，直接拖动调整，无数字输入弹窗。拖动仅预览，松手提交一次，可撤销；取消或双指接管不会修改笔记。缩小未触及笔迹时直接提交；触及笔迹或文字会询问移动、删除或取消。删除策略仍是相交整笔。留白编辑模式可双指平移缩放。

“已保存”代表事务提交成功；每条完成笔迹异步保存，切后台结束当前笔迹并排队保存。失败会按文件显示状态，可在画笔面板重试。返回笔记库和关闭文件等待保存。首页提供全库 ZIP 备份与恢复；恢复先校验后添加副本，保留现有笔记。

图像PDF导出可选择标准/较清晰，长页保留留白，但源文本和矢量对象栅格化。先写临时文件并验证能重开/页数，再通过SAF写入新文件。失败不修改源笔记。

## 架构和限制

见 ARCHITECTURE.md、DECISIONS.md、KNOWN_ISSUES.md、LICENSES.md。当前页位图限制6M像素；在写笔迹前景与已完成页面缓存分开。这不等于完成Tile/front-buffer引擎或达到实测毫秒指标。撤销为当前会话页级快照，最多30项并限制历史内存，重启不保留撤销历史。S3完整工具、S4 Android端恢复验收和S5分档性能待推进。

## 0.4 新增

- 压感钢笔：力度影响粗细，实时笔迹、重开和 PDF 导出共用渲染；荧光笔与关闭压感后的钢笔保持固定粗细。旧笔迹保持原样。
- 触控笔按触点 ID 跟踪，混合手掌事件不打断笔迹；默认防误触开启，书写模式使用双指移动/缩放，笔尖接近或接触时拒绝手指输入。大面积手指启发式过滤可关闭，并依赖设备本身报告的输入信息。
- 系统取消/误触取消撤掉当前临时笔迹，不写入笔迹或撤销历史；橡皮取消恢复原页面。
- 「沉浸书写」隐藏状态栏、导航栏及次要模块，保留紧凑工具条、退出入口和保存状态。边缘滑动可临时唤出系统栏，返回键先退出沉浸。工具条可展开/收起，当前笔种再次点击切换选笔面板。
- 紫色强调、白灰背景和更平直的控件。并非全部 Goodnotes 功能已经完成。
- 本轮原签名密钥不可用，Debug 包使用独立的 `cn.jiang.opennote.preview`，应用名「OpenNote 预览」，与旧版并行安装。旧库通过 ZIP 备份/恢复添加副本迁移；不要卸载原应用。本机预览签名通过 `OPENNOTE_DEBUG_KEYSTORE` 复用，密钥不随工程交付。

## 0.3 新增

- 原生可折叠工具栏、文件标签、选笔面板、持久笔盒、页内笔记与翻页模块。
- 白色与浅灰平面布局、蓝色强调，轻量尺寸与透明度动画；模块尺寸变化时保留阅读缩放比例。
- 拖动创建留白与原位高度手柄，预览不改模型，松手才产生一次编辑。
- 留白扩展的内容移动与撤销命令，超限输入在记录撤销前拒绝。
- 待保存页面批量事务、保持最新标题/页码、文件级失败提示；导出前先提交待保存内容。

## 0.2 新增

- 首页标题搜索、重命名、备份全部、恢复备份预览。
- 流式 ZIP + SHA-256 清单；二进制笔迹、源 PDF、留白布局和文字卡片；有取消和临时空间预检查。
- 恢复前校验路径、条目数量、解压大小、压缩比、版本、源 PDF 页数和数据；添加副本，不覆盖现有库；事务失败回滚，并用恢复日志清理崩溃留下的目录。
- SQLite 大笔迹分块读取，避免单个 BLOB 超过 CursorWindow；已写 10 万点单笔的 Android 测试，Android用例已通过，详细记录见报告。
- 返回笔记库等待保存成功；失败保留编辑页和待保存快照，可重试所有未提交页面；耗时任务期间阻止落笔。

备份格式见 `docs/BACKUP_FORMAT.md`。当前恢复仅“添加副本”，尚无替换/去重/文件夹树；设置写入备份但恢复保留本设备偏好。ZIP64 65,536 个条目已通过主机测试；超过 4 GB 的单个文件和 Android ZIP64 仍需实测。安全限制为 16 GiB 解压总量、100,000 条目、超过 1 MiB 文件压缩比最多 200。异常高压缩比的合法备份也可能被拒绝，拒绝时源库保持不变。

## 已安装首版时的升级限制

0.2 更换过开发签名；0.3 沿用 0.2 的签名，可覆盖该版本，但与 0.1 的证书不同，不能覆盖安装 0.1。**不要为了强行升级而卸载保存有笔记的旧版。**需要取得原签名密钥或制定数据迁移流程；本开发版 APK 不构成无损覆盖升级包。正式稳定签名和发行流程待建立，签名密钥不提交 Git。

0.4 验证结果见 TEST_REPORT.md；0.3 历史报告见 docs/verification/TEST_REPORT-0.3.md；0.2 的历史 22+6 项通过记录保留于 docs/verification。真实平板动画帧率、笔尖延迟、30分钟和GB级PDF仍未验收。

书写平滑：已原生适配 perfect-freehand 的位置 streamline 步骤，可在画笔面板关闭；逐笔保存模式，原始样本保留。实际移植范围、MIT 许可和检查命令见 [开源笔迹说明](docs/OPEN_SOURCE_INK.md)。
