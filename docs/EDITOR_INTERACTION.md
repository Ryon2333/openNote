# 0.3 编辑器交互验收

目标：Goodnotes 类选笔组织方式，微软平面视觉风格；采用原生 Compose + Android View，不使用第三方品牌素材。

## 页面操作

1. 打开示例，工具栏选择钢笔；画笔面板显示颜色、连续粗细控制和线条预览。
2. 配置红色细笔与黄色荧光笔，分别加入笔盒。点预设切换，再启动应用确认笔盒仍在。
3. 整理笔盒，移除一支；展开/收起笔盒不会删除预设。空笔盒应在重启后仍保持空。
4. 逐个收起文件、工具栏、选笔、笔盒、页内笔记和翻页模块；再展开。记录真机是否出现闪烁、书写区域跳动或明显掉帧。
5. 打开第二本笔记，两本各写一笔、换页，在标签间切换；确认页码、缩放/阅读位置、笔迹与会话撤销保留。关闭文件后从笔记库重开，验证提交内容。
6. 插入留白模式按住页面向下拖：跟随预览，松手插入。已有留白拖底部蓝色手柄，数值跟随，原内容同步移位。无需输入像素或毫米。
7. 拉动后取消或第二指接管，布局与撤销数不变。缩小空白直接应用；缩到笔迹/文字时先选择处理方式，取消保留原布局。
8. 留白创建/扩大后分别撤销、重做，保存后重开，再导出 PDF 核对源内容与笔迹位置。

## 验证范围

主机模型测试检查扩展命令、位置移动、一次撤销和越界拒绝。
Android 存储用例还检查批量提交中途失败完整回滚、快照保留、重试、标题与阅读页码保持最新。
Android 原生手势用例检查预览阶段不修改、松手仅回调一次、手柄扩展和取消不提交。
UI 动画、文件切换与笔盒操作仍须真实平板按上面步骤验收；未提供毫秒延迟或稳定帧率承诺。
