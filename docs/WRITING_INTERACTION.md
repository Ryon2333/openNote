# 0.4 书写与沉浸验收

1. 安装「OpenNote 预览」，保留旧应用。旧版备份全部为 ZIP，在预览版恢复并检查页数、标题、笔迹和留白；两份库独立。
2. 打开示例选择钢笔，画笔面板开启压感。分别用轻、重力度写横线、连续曲线；粗细应自然过渡。关闭压感应恢复固定宽度。荧光笔保持固定宽度。保存重开、撤销/重做、加入留白并导出，检查笔迹粗细一致。
3. 在画笔面板切换「笔迹平滑」，用小字、折角和点画比较。设置仅影响后续钢笔笔迹；保存重开、留白与导出应保留每条笔迹自己的平滑模式。
4. 开启手掌防误触、关闭手指书写。手掌先落下再用笔、笔先落下再落掌；笔迹不能跳到手掌坐标，掌不能推动书写页或打断笔迹。提笔后立即移动手掌仍应受到短暂保护。双指可移动缩放，笔尖接触时优先写字。
5. 无笔时可在设置开启手指书写；误触过滤过于严格时关闭防误触。不同设备压力范围、接触面积与系统取消信息会有差异，需在 OPPO Pad 5 实测。
6. 「沉浸书写」隐藏双系统栏、文件标签和侧面板，留下紧凑工具条及保存状态；展开/收起工具栏，换笔/撤销；再次点击当前笔种收起选笔。边缘滑动临时唤出系统栏，退出/返回键恢复正常界面。
7. 在笔划进行中切后台，正常结束并保存当前笔迹；系统误触取消则撤掉当前临时笔迹。取消整笔擦应恢复原笔迹，不能污染撤销历史。保存失败仍有可见状态并可重试。
8. 平板横/竖屏、全屏/窗口、手掌不同放置角度、不同笔尖压力、持续30分钟分别记录体验；软件模拟器通过不代表压力硬件、误触识别、帧率或延迟验收。

备份笔迹编码升级为3，可读版本1/2。新备份不要恢复到不支持版本3的旧应用。
