## 保存和同步

页面销毁时释放当前 PDF 位图，过期渲染结果及时回收。文件切换前捕获并排队保存当前页面；关闭标签等待相关待保存快照提交，失败保留标签。各文件独立标记保存失败；关闭、重试和导出先以事务提交该文件的待保存页面，失败整批回滚并保留快照，同时保留最新标题与页码。文件标签、视口与撤销历史属于当前会话，笔盒使用设备偏好存储。跨文件切换/关闭的完整真机回归步骤见 docs/EDITOR_INTERACTION.md。

GitHub 推送仍缺少身份验证，不能称为已经同步或远程 CI 已运行。APK 继续采用 0.2 的开发签名；已核对证书 SHA-256 为 `2e4cecad9b46cc261ec73a2d4b0cf2609aa5155fcbdc33220b528dde6dafec55`，与 0.2 一致；本轮签名验证通过。0.1 的签名不同，历史升级限制仍在。

## 尚未验收

- OPPO Pad 5 上动画帧率、触控笔延迟、连续 30 分钟书写。
- 真实设备多文件切换、系统强杀、低存储和文件选择器流程。
- 大量笔迹页的拖动预览性能、GB 级 PDF 与高缩放 Tile。
- 基础钢笔为固定宽度，未实现真实钢笔尖压力曲线、局部擦除和形状识别。
- 笔盒设备偏好写入，重启恢复仍需进程终止/设备重启实测；仪器用例仅验证 Activity 重建。
- 模块动画为 180–220ms 尺寸/透明度变化，不能仅凭编译或软件模拟器推断真实平板流畅度。
