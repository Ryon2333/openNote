# OPPO Pad 5 真机验收（尚未执行）

Android 13+；先用示例和试卷副本，飞行模式关闭 Wi-Fi。

1. 打开内置示例，再导入实际试卷。核对页序、方向、混合尺寸，测试损坏/加密文件错误退出。
2. 触控笔写积分号、矩阵、汉字、长横线、快速圈画；手指平移、双指缩放、掌触抑制。单独记录设备压感和侧键能力。
3. 第 18/19 题分界插入 80 mm（226.77 pt），检查下方源 PDF 和笔迹下移；留白内继续书写。
4. 页首、页尾、多处和已有留白内部插入；调整/缩小/删除时测试取消、保留、删除相交整笔及撤销/重做。
5. 等到“已保存”后退后台、强制停止、重开；对比留白、笔迹、文字、当前页。另测保存中杀进程，记录提交边界，不假定未提交数据已保存。
6. 切页后撤销上一页操作，检查显示的是正确源页。
7. 导出 168/240 dpi 图像 PDF，用其他阅读器核对页数、高度、留白、中文、数学公式和荧光笔。源可选择文本不保留。
8. 连续书写30分钟，Perfetto/Profiler记录帧时间、输入显示延迟p50/p95、Java/Native/Bitmap内存和发热；无记录就标未测。
9. 分档测试10/100/500MB、1/2/4GB扫描/矢量PDF，记录页数、可用空间、导入/首屏/翻页时间、内存及失败原因。
10. ZIP64全库恢复、文件夹、套索和局部擦除尚未交付，不列作已通过。

## 0.2 备份与交互追加用例

1. 空库备份恢复、两个文档备份恢复；留白中手写和中文卡片，恢复后再次插入/调整留白、再书写、再备份。核对源PDF哈希、笔迹数/内容、留白、页序和元数据。
2. 导入篡改/未来版本/异常压缩比ZIP；操作应被拒绝，原库不变化。复制和解压阶段取消，临时文件应清理。
3. 确认恢复预览的信息，取消不添加；添加副本保留旧笔记；重复恢复产生重复副本，提示与结果一致。
4. 模拟SQLite失败/磁盘满，返回笔记库不得丢掉编辑页；跨页未保存修改可重试后重开。
5. 页面转向、字体放大、搜索无结果、重命名空标题、恢复时误落笔；检查触控目标与可读性。
6. 不可拿0.2覆盖不同签名0.1，不要卸载有数据旧版；正式发行前必须验证稳定签名的无损升级。
